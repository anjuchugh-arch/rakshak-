
# RAKSHAK DRIVE
### Intelligent Road Safety System

## About the Project

RAKSHAK DRIVE is an educational road-safety innovation concept that demonstrates how AI-inspired object recognition and proximity alerts could help identify pedestrians and animals near vehicles.

## Key Features

- Pedestrian detection simulation
- Animal detection simulation
- 50-metre warning threshold
- Audio warning demonstration
- Vibration alert demonstration
- Interactive monitoring dashboard
- Detection event history

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Audio API
- Browser Vibration API

## How to Run

1. Download all project files.
2. Keep all six files in one folder.
3. Open index.html in a browser.
4. Select Detect Person or Detect Animal.
5. Adjust the distance slider.
6. Observe the warning dashboard.

## Project Objective

To explore innovative and accessible road safety technologies.

## Important Safety Notice

This is an educational software simulation. It does not perform real-world AI detection, measure actual distances or control a vehicle. It must not be used as a real driving safety device.
